# AGENTS.md — rust/crates/ffi

Фасад `MeetingCore` — весь контракт с Swift. Общие правила границы
(ошибки строками, один мьютекс, ломающийся `Ffi*`-конструктор) — в
корневом `AGENTS.md`; здесь только то, что видно из этого каталога.

## Устройство крейта

- Пакет `meetingraft-ffi`, но `[lib] name = "meetingraft_ffi"` — **с
  подчёркиванием**; `uniffi.toml` повторяет `cdylib_name =
  "meetingraft_ffi"`. `crate-type = ["cdylib", "lib"]`.
- Фичи: `default = []`, `whisper = stt/whisper`, `diarize =
  diarize/model`, `gigaam = stt/gigaam`. `parakeet` и `tone` намеренно не
  пробрасываются.
- Зависимости: все core-крейты + `serde_json`, `uniffi` 0.32, `uuid`;
  dev — `mockito`, `rusqlite` (bundled). `rusqlite` нужен тесту, который
  портит колонку в БД.

## Файлы

- `src/lib.rs` (~6500 строк) — весь контракт с Swift: `MeetingCore`,
  `Ffi*`-DTO, экспорты. Всё состояние — в `MeetingCoreInner`.
- `src/rebuild.rs` — долгий путь пересбора финала.

## Пересбор вне мьютекса

`run_rebuild` идёт **отдельным потоком вне мьютекса ядра**, со своим
соединением SQLite. Иначе проход держал бы `MeetingCore` минутами, а
`drain_events` нужен каждые 50 мс. Ошибки возвращаются строками.

Ветки без фич живут в `rebuild.rs` и ведут себя **по-разному**, и это
намеренно. Без `whisper` (`rebuild.rs:286-299`) проход не отказывает:
подставляется `MockBatchTranscriber`, а в note честно сказано «mock
re-ASR» — иначе весь post-call путь был бы непроверяем вне Мака. Без
`gigaam` (`rebuild.rs:322-331`) — жёсткая ошибка `Err("сборка без
--features gigaam…")`: сюда попасть нельзя, и ветка нужна, чтобы свойство
держал компилятор, а не память. У `diarize` так же: `lib.rs:648` —
положительная ветка, `lib.rs:654` — `Err`.

## Инварианты, записанные здесь

- **Кнопка, которая всегда отказывает, — заглушка** (`lib.rs:4854-4867`).
  Без фичи ветку голосовой памяти надо **прятать**, а не отказывать по
  клику. Тест утверждает от `cfg!`, а не от константы: перестань ответ
  зависеть от фичи — тест покраснеет.
- **Выключено значит пусто** (`lib.rs:2569-2572`). Выключение голосовой
  памяти стирает сохранённые векторы; иначе на диске лежит биометрия,
  которую человек считает выключенной.
- **Порог свёртки дублей по умолчанию `None` = выключено**
  (`lib.rs:441-447`). Включить до чисел `dup-probe` — значит молча решить,
  сколько речи выбросить.
- **Порог voiceprint 0.45 — середина** измеренного окна 0.40…0.50, не
  край (`lib.rs:4870-4879`); тест это фиксирует.

## Соглашения

- Приватные хелперы внутри блока `#[uniffi::export]` пишутся **свободными
  функциями**, а не приватными методами: метод там всё равно пытается
  пройти через границу.
- `unsafe` в крейте нет.
