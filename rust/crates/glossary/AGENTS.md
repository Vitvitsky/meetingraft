# AGENTS.md — rust/crates/glossary

Нормализация терминов, CSV-импорт, добыча кандидатов. Разделение видов —
причина дефекта Epic 19; правило живёт здесь.

## Устройство

Пакет `meetingraft-glossary`, lib `glossary`. Зависимости: `domain`, `uuid`.
Модули: `csv_import`, `engine`, `mine`, `normalize`.

## Виды терминов

`normalize_with_kind` **требует вид**:
- `Hint` — не переписывает готовый текст, но всё равно едет в
  `initial_prompt` Whisper (`build_whisper_prompt`);
- `Replacement` — переписывает вхождения.

Слить виды нельзя: подсказка, начавшая заменять, портит текст молча.

## Порядок и промпт

- Побеждает длинная surface: `from_terms` сортирует по убыванию числа
  символов — иначе короткий термин перехватит длинный.
- `build_whisper_prompt(max_chars)`: дедуп по canonical, приоритет
  ru < en < es, обрезка по числу символов.

## CSV

Колонки строго `surface,canonical,language,scope` (+ опциональный
`meeting_id`). Битые строки **пропускаются и считаются**, а не роняют
импорт: одна опечатка не должна отменять весь файл.
