# AGENTS.md — rust/crates/storage

Локальное состояние: SQLite, файлы аудио, журнал диагностики. Правила
«выключено значит пусто» общие — здесь то, что видно из этого каталога.

## Устройство крейта

Пакет `meetingraft-storage`, lib `storage`. Зависимости: `flac-codec`,
`domain`, `rusqlite` (**bundled**), `thiserror`. Фич нет.

Модули:
- `audio_manifest` (~4600 строк) — манифест сессий в SQLite + чанки на
  диске.
- `diagnostics_log` — JSONL, **только локально, никуда не уходит**.
- `migrations` — шаги по `PRAGMA user_version`.
- `segment_edits` — правки текста сегментов (вынесены, когда
  `audio_manifest` разросся).

## Правила миграций

- `migrations.rs:129-132` — миграция **не меняет** поведение уже
  существующих терминов глоссария: умолчание 1 = Replacement, термины
  писали руками.
- `migrations.rs:141-157` — ключ позиции правки `(channel,start,end)` —
  это **договор трёх слоёв**, а не ограничение схемы: уникального индекса
  и внешнего ключа намеренно нет. Все три места обязаны ходить через
  `domain::edits_by_position`; четвёртое, посчитавшее ключ само, разойдётся
  молча.
- `migrations.rs:190-193` — **не менять порядок шагов 9 и 10**: шаг
  `codec` уже уехал в `main`, перестановка добавит его заново и упадёт на
  настоящих БД.
- `migrations.rs:207-218` — миграция 12 добавляет признак источника;
  умолчание `human` — безопасная сторона (правку человека, названную
  массовой, перепишут молча; массовую, названную человеческой, просто не
  тронут).
- Шаг 1 — `CREATE TABLE IF NOT EXISTS`, чтобы БД до версионирования
  обновлялись без потерь.

## Выключено значит пусто

- `diagnostics_log.rs:178` — выключенный журнал не создаёт **файл**: иначе
  «выключено» лжёт.
- `audio_manifest.rs` `set_known_voices_enabled` — выключение голосовой
  памяти **стирает** запомненные слепки (биометрия). Слепки при встречах
  не трогаются: они живут при своих записях. В комментарии это названо
  тем же выбором, что у журнала диагностики.

## Тестовые данные

- `audio_manifest.rs:3312` — тексты фикстур обязаны быть **разными**. Совпали
  — тест проходит, ничего не проверив.
