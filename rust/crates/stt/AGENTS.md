# AGENTS.md — rust/crates/stt

Распознавание речи: живой путь, batch-проход для post-call и второй
движок (GigaAM). Объяснение whisper/GigaAM за фичей — в корневом
`AGENTS.md`; здесь карта модулей и измеренные ловушки.

## Фичи и платформа

Пакет `meetingraft-stt`, lib `stt`. `default = []`.
`whisper = dep:whisper-rs`; `gigaam`, `parakeet`, `tone`, `vad` —
`dep:sherpa-onnx` (сеть на сборке). Ускоритель выбирается **по
платформе**: `cfg(target_os = "macos")` → Metal, иначе CPU (нужен cmake).
Без фичи и без модели `stt_backend()` отдаёт `mock`.

## Карта модулей (собираются всегда)

- `batch` — batch-транскрайбер для post-call, отдельный от живого
  `SttEngine`.
- `echo` — детекция эха говорящего по корреляции с системным каналом;
  сигнал не меняется.
- `engine` — трейт `SttEngine`.
- `engine_choice` — **`decide_batch_engine` живёт здесь, а не в `ffi`**.
  `auto` ключуется по `primary`, потому что `allowed` всегда `{ru,en,es}`,
  а латиницы нет в словаре GigaAM.
- `gigaam_path`/`parakeet_path`/`tone_path`/`vad_path` — поиск моделей,
  **имена файлов зашиты, никогда не по маске**.
- `hallucination` — отсев галлюцинаций (см. ниже).
- `hypothesis` — гипотезы для local agreement.
- `local_agreement` — LocalAgreement-2, от модели не зависит.
- `mock` — заглушка по умолчанию.
- `model_path` — поиск ggml Whisper; держит кастомный тестовый хелпер
  `fn tempfile()`.
- `noise_gate` — адаптивный порог (см. ниже).
- `pacing` — `InferencePacer`.
- `speech_decider`, `window` (`cfg(whisper)` берёт Whisper, иначе Mock).

Гейтятся фичей: `gigaam`, `parakeet`, `tone`, `vad` + `vad_segments`,
`whisper` + `whisper_batch`.

## Ловушки (замерено)

- **`hallucination.rs` — про Whisper.** Проверка титров — это основа+глагол,
  и глагол обязан идти **после** основы. Неполный список фраз пропустил
  «Субтитры подогнал …» 5-10 раз за встречу. Префикс-галлюцинацию
  **придерживают, а не выбрасывают**: «субтитры» — настоящее слово.
  Переносить эти фильтры на GigaAM нельзя.
- **`noise_gate.rs`: постоянный порог RMS измеренно сломан** — 6.9 Вт на
  GPU при шуме открытого окна; поднять порог — пропадёт тихий говорящий у
  системного канала. Смысл в адаптивном полу: `SPEECH_MARGIN = 3.0`,
  `ABSOLUTE_FLOOR = 120`, медленный подъём / быстрый спад. `frame_rms`
  лежит рядом с гейтом, чтобы приборы мерили **тот же** гейт: приватная
  копия расходится молча.
- **`hypothesis.rs`: биасинг глоссарием работает только на
  `modified_beam_search`.** На greedy он молча ничего не делает. «Работает
  только когда замер показал разницу» — и по пойманным терминам, и по
  ложным притяжениям.
- **`vad_segments` намеренно отделён от `SileroGate`:** гейт выбрасывает
  сегменты, режим сегментов их собирает. Минимумы VAD прижаты, чтобы наша
  нарезка осталась единственным сегментатором.
- **`gigaam.rs`: параметры признаков берутся из метаданных ONNX**, а
  `feat_config` на этот экспорт не влияет вовсе (уверенный комментарий
  однажды утверждал обратное и не делал ничего).
