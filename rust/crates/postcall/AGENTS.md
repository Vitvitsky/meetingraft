# AGENTS.md — rust/crates/postcall

Сборка финала, правки, спикеры, артефакты. Это единственный крейт с
настоящими HTTP-клиентами LLM; правила промптов и безопасности — здесь.

## Устройство крейта

Пакет `meetingraft-postcall`, lib `postcall`. Зависимости: `domain`,
`glossary`, `reqwest` (blocking/json/rustls-tls), `serde`, `serde_json`,
`thiserror`; dev — `mockito`. Ребро `postcall → glossary` — единственная
связь между core-крейтами, кроме `ffi → все`.

Модули:
- `assemble` — сборка финала (`assemble_final`).
- `corrections` — правки по всей расшифровке от LLM.
- `dedup` — свёртка дублей (`collapse_doubles`).
- `diff` — `diff_words`, живое против финала.
- `edit_service` — чистые `plan_edit`/`occurrences_to_edit`, без записи;
  единственный `#[allow(too_many_arguments)]`.
- `edits` — перепривязка правок по перекрытию времени и исходному тексту,
  **не по индексу**.
- `jobs` — `RebuildJobs` + трейт `Spawner` (детерминизм в тестах).
- `llm` — `LlmClient`/`NullLlmClient`.
- `llm_http` — `OllamaNativeClient`/`OpenAiCompatLlmClient`.
- `merge` — сведение каналов по известной идентичности, без эвристики RMS.
- `polish` — переписывает текст **внутри сегмента**; молчаливого отката
  нет, `PolishReport` говорит правду.
- `prompts`, `speakers`, `templates`, `term_from_edit`.

## Правила LLM и промптов

- **Предложения по всей расшифровке не применяются автоматически.** Модель
  не слышит аудио; молчаливое применение испортило бы финал.
- `prompts.rs:8-35` — три вещи повторяются в **обоих** промптах: что за
  текст, как читать имена, что запрещено. Задача повторяется **после**
  расшифровки (на ~30k знаков побеждает последняя инструкция). Формат
  вывода задаётся явно: «верни Markdown» ничего не запрещает. `preamble` и
  `output_rules` — общие строки, расходиться между брифом и follow-up не
  должны.
- Свёртка дублей: порог `collapse_doubles` — **обязательный параметр, без
  умолчания**; Final никогда не мутируется на месте.

## Приоритет спикеров

Живёт в `domain/src/postcall.rs:145-167`: **человек → канал → voiceprint**.
Решение человека не перезаписывается никогда; значение канала — массовое
умолчание и **перезаписывается** voiceprint (первая редакция ADR-013 это
запрещала, и правило не могло сработать: пересбор ставит канал на все
сегменты).

## Смежное

`bench/src/labels.rs:5-13` — непроверенный текст **никогда** не попадает в
эталон: авторазметка «верно» запрещена, потому что согласные движки
ошибаются одинаково.
