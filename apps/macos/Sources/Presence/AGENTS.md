# AGENTS.md — apps/macos/Sources/Presence

Меню-бар, оверлей, детектор встреч. Единственное место с окнами AppKit.
Отказ здесь молчаливый: запись идёт, а признака нет.

## Оверлей

- Оверлей — `NSPanel` (borderless, nonactivating, floating, все
  пространства, fullScreenAuxiliary), не окно SwiftUI. `preferredColorScheme`
  до него **не доходит**: тема передаётся явно при каждом `show`. Забыть —
  получить тёмную панель поверх светлого приложения ровно в сценарии со
  свёрнутым окном.
- `PresenceDecision`: главное окно **никогда** не прячется без оверлея —
  иначе записи не видно; вне записи оба состояния сбрасываются независимо
  от настроек.
- Запоминается **именно** спрятанное окно, а не «первое»; `NSPanel` при
  выборе пропускается.

## Детектор и мост

- `MeetingDetector` различает только запуск приложения, никогда — идёт ли
  звонок (обещание приватности). Порядок — как в системном списке
  приложений, не по нашему перечислению.
- `MenuBarIcon` различается **формой**, не цветом (меню-бар монохромный).
- `RecordingBridge` существует потому, что `MenuBarExtra` — отдельная сцена
  без координатора.
