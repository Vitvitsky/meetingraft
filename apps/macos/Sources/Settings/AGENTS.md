# AGENTS.md — apps/macos/Sources/Settings

Экран настроек. Открывает **свой** `MeetingCore` — не то ядро, что `Shell`.

## Порядок загрузки

`SettingsModel.load()`: `refreshPostCallEngine()` **до**
`applyPostCallRecognizer()`. Наоборот — сохранённый выбор применится к
ядру, которое уже не видит модель.

## Готовность движка

Готовность русского движка берётся из ядра (`gigaamModelReady()`), а не из
успеха загрузки: сборка может быть без фичи `gigaam`, и скачанный файл
ничего не значит.

## Голосовая память

До открытия ядра читается как выключенная. Выключение **забывает все**
голоса и говорит об этом до клика.

## Список моделей

Семь разделов фиксированы спекой; заголовки не должны протекать ссылками на
ADR. Пустой каталог и ошибка связи различаются отдельной проверкой
здоровья: FFI отдаёт ошибку sync как пустой список, и без проверки сбой
выглядит как «моделей нет». Перед удалением — прогон-превью; пропущенные
записи называются вслух.
