# AGENTS.md — apps/macos/Sources/Meetings

Список встреч, детали, финальный пересбор, атрибуция спикеров. Три
протокола ядра (`MeetingsCoreProviding`, `FinalRebuildCoreProviding`,
`SpeakerAttributionCoreProviding`) и AVFoundation-плеер. Общие границы и
локализация — в `apps/macos/AGENTS.md`.

## Версии и сегменты

- `selectedFinalVersion == nil` значит «последняя» **и для тела, и для
  атрибуции**. Принять это за «версии нет» — показать текст без сегментов:
  правка и воспроизведение выглядят мёртвыми на живых данных.
- Сегменты есть только у версий, пересобранных с re-ASR (ADR-011). Старые
  финалы показывают markdown с пометкой. Атрибуция без версии до ядра
  доходить не должна — иначе правка уедет в чужую расшифровку.

## Плеер

`SegmentAudioPlayer` — отдельный объект с `AVAudioEngine`: переживает
перерисовку списка. `sampleRate == 0` значит «для этого диапазона записи
нет», а не сбой; кнопка воспроизведения тогда прячется.

## Спикеры и правки

- `upsertSpeaker` пересобирает markdown всей встречи: пустое или
  неизменённое имя не коммитить на потере фокуса.
- Неприменённые правки нельзя «вернуть назад»: `originalText` — и ключ
  поиска, и метка отката. Копируется только текст.
- `MarkdownExport` пишет один файл и отката не делает; откат уже
  записанных файлов при ошибке ввода-вывода — в
  `MeetingsViewModel.exportMarkdown`. Имя `YYYY-MM-DD-shortid-kind.md`.
  Удаление аудио отделено от удаления встречи (Epic 22).
