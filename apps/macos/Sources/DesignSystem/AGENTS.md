# AGENTS.md — apps/macos/Sources/DesignSystem

Токены и компоненты. Чистая презентация: цвета, отступы и типографика
определяются здесь и только здесь.

## Токены

- Токены заданы один раз в `Theme`; экраны не заводят свои цвета и отступы.
- Две темы — через `NSColor(name:)` provider (`bestMatch` `.aqua`/`.darkAqua`).
  Светлая палитра **вычисляется по контрасту, а не подбирается на глаз**.
- `textOnStatus` намеренно инвертирован относительно `textPrimary`:
  заливки статусов выбраны по контрасту со страницей.

## Контраст

- Пороги ступенчатые: `textTertiary` — 3.0, остальные — 4.5. Выключенный
  текст не проверяется; прозрачные токены не аудируются.
- Предупреждение в светлой теме — оранжевое: жёлтый даёт 1.41:1.
- SF Pro — решение (Inter отменён 2026-08-20).
