# Стенд сравнения распознавателей — план работ

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans
> to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** прибор, который гоняет одни и те же записи через разные движки и
разные способы нарезки и печатает числа, по которым выбор делается, а не
обсуждается.

**Architecture:** отдельный крейт `meetingraft-bench` (в приложение не
входит, как остальные приборы). Вход — каталог случаев с WAV и эталоном,
а не база приложения: данных приложения на Linux-машине нет. Оси —
движок × нарезка × смещение; каждый прогон кладёт `run.json` и
читаемую расшифровку. Движки прячутся за фичами по образцу
`stt/gigaam` и `diarize/model`.

**Tech Stack:** Rust 2024, sherpa-onnx 1.13 (уже слинкован), serde + toml,
существующие крейты `stt`, `diarize`, `storage`, `domain`.

**Spec:** `docs/superpowers/specs/2026-08-28-asr-bench-design.md`

## Global Constraints

- **Комментарии и документация в коде — по-русски**, идентификаторы —
  по-английски (`AGENTS.md`).
- **Коммиты — Conventional Commits, английский subject и body.**
- **Полный `cargo test` по workspace не влезает в память этой машины.**
  Гонять по крейтам: `cargo test -p meetingraft-bench`.
- **Имя пакета с префиксом**: каталог `crates/bench` — пакет
  `meetingraft-bench`; `-p bench` не найдёт ничего.
- **Фичи движков выключены по умолчанию.** `build.rs` крейта `sherpa-onnx`
  ходит в сеть; обычная сборка и CI не качают ничего.
- **Формат звука один**: 16 кГц, моно, `i16` (ADR-005). Всё остальное —
  отказ с причиной, а не молчаливый ресемпл.
- **Заведомо положительный и заведомо отрицательный случай обязательны**
  до настоящих данных (`AGENTS.md`). Прибор, не показавший ненулевое там,
  где оно заведомо есть, не верится.
- **Отказ едет отдельным полем, а не пустым результатом.** Пустой список
  сегментов означает «речи не нашли», отказ — `refused: Some(причина)`.
- Линт перед коммитом: `cargo fmt --check && cargo clippy -p meetingraft-bench --all-targets -- -D warnings`.

```rust
//! Чтение WAV — общее с приборами, запись — своя.
//!
//! Читает разбор соседнего прибора **тем же файлом** (как `stt-probe`):
//! формат один — 16-битный моно PCM живого пути, — и вторая реализация
//! разошлась бы с первой. Запись нужна только здесь: её пишет `export`,
//! выкладывая встречу из данных приложения в случай.

#[path = "../../diarize-probe/src/wav.rs"]
mod reader;

pub use reader::{Wav, read};

use std::path::Path;

/// Записать 16-битный моно PCM.
pub fn write(path: &Path, pcm: &[i16], sample_rate: u32) -> Result<(), String> {
    let data_bytes = (pcm.len() * 2) as u32;
    let mut out = Vec::with_capacity(44 + pcm.len() * 2);
    out.extend_from_slice(b"RIFF");
    out.extend_from_slice(&(36 + data_bytes).to_le_bytes());
    out.extend_from_slice(b"WAVEfmt ");
    out.extend_from_slice(&16u32.to_le_bytes()); // размер fmt
    out.extend_from_slice(&1u16.to_le_bytes()); // PCM
    out.extend_from_slice(&1u16.to_le_bytes()); // моно
    out.extend_from_slice(&sample_rate.to_le_bytes());
    out.extend_from_slice(&(sample_rate * 2).to_le_bytes()); // байт в секунду
    out.extend_from_slice(&2u16.to_le_bytes()); // выравнивание блока
    out.extend_from_slice(&16u16.to_le_bytes()); // бит на отсчёт
    out.extend_from_slice(b"data");
    out.extend_from_slice(&data_bytes.to_le_bytes());
    for sample in pcm {
        out.extend_from_slice(&sample.to_le_bytes());
    }
    std::fs::write(path, out).map_err(|error| format!("{}: {error}", path.display()))
}

#[cfg(test)]
mod tests {
    use super::*;

    /// Записанное читается обратно тем самым разбором, которым живут
    /// приборы. Своя запись, разошедшаяся со своим же чтением, — самый
    /// тихий способ подать движку чужой звук.
    #[test]
    fn what_we_write_our_own_reader_reads_back() {
        let path = std::env::temp_dir().join(format!("bench-wav-{}.wav", std::process::id()));
        let pcm: Vec<i16> = (0..1000).map(|i| (i * 7) as i16).collect();
        write(&path, &pcm, 16_000).expect("записать");
        let back = read(&path).expect("прочитать");
        assert_eq!(back.sample_rate, 16_000);
        assert_eq!(back.pcm, pcm);
    }
}
```

- [ ] **Step 5: Написать `case.rs`**

```rust
//! Случай стенда: звук, описание, эталон.
//!
//! Стенд читает **каталог**, а не базу приложения. Это не удобство:
//! данных приложения на Linux-машине нет вовсе, и зависимость от них
//! означала бы прибор, который здесь не запускается.

use std::path::{Path, PathBuf};

use serde::Deserialize;

use crate::wav;

/// Частота живого пути (ADR-005). Всё остальное — отказ.
pub const RATE: u32 = 16_000;

/// Как получен эталон.
///
/// Различие несущее: правленный черновик движка **систематически льстит**
/// тому движку, с которого черновик взят, и заметить это в числе нечем.
/// Отчёт печатает пометку сам, а не надеется на память читателя.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Deserialize)]
#[serde(rename_all = "kebab-case")]
pub enum ReferenceKind {
    /// Напечатан с нуля.
    Typed,
    /// Правленный черновик движка.
    EditedDraft,
    /// Эталона нет.
    None,
}

#[derive(Debug, Clone, Deserialize)]
pub struct Meta {
    pub case: String,
    pub language: String,
    #[serde(default)]
    pub speakers_expected: u32,
    pub source: String,
    #[serde(default)]
    pub channel_clock_unified: bool,
    pub reference_kind: ReferenceKind,
    /// Какой отрезок покрыт эталоном, мс. WER считается только по нему.
    #[serde(default)]
    pub reference_covers_ms: Option<[u64; 2]>,
    #[serde(default)]
    pub notes: String,
}

#[derive(Debug)]
pub struct Case {
    pub dir: PathBuf,
    pub meta: Meta,
    pub sample_rate: u32,
    pub mic: Vec<i16>,
    pub system: Option<Vec<i16>>,
    pub reference: Option<String>,
}

impl Case {
    /// Длина записи в миллисекундах — по микрофонному каналу.
    pub fn duration_ms(&self) -> u64 {
        self.mic.len() as u64 * 1000 / u64::from(self.sample_rate.max(1))
    }
}

pub fn load(dir: &Path) -> Result<Case, String> {
    let meta_path = dir.join("meta.toml");
    let text = std::fs::read_to_string(&meta_path)
        .map_err(|error| format!("{}: {error}", meta_path.display()))?;
    let meta: Meta =
        toml::from_str(&text).map_err(|error| format!("{}: {error}", meta_path.display()))?;

    let mic = read_channel(&dir.join("mic.wav"))?;
    let system = match dir.join("system.wav") {
        path if path.exists() => Some(read_channel(&path)?),
        _ => None,
    };

    // Объявленный эталон, которого нет на диске, — отказ. Молчаливое
    // «эталона нет» дало бы прочерк в отчёте там, где потерян файл.
    let reference_path = dir.join("reference.txt");
    let reference = match meta.reference_kind {
        ReferenceKind::None => None,
        _ => Some(
            std::fs::read_to_string(&reference_path)
                .map_err(|error| format!("{}: {error}", reference_path.display()))?
                .trim()
                .to_string(),
        ),
    };

    Ok(Case {
        dir: dir.to_path_buf(),
        meta,
        sample_rate: RATE,
        mic,
        system,
        reference,
    })
}

fn read_channel(path: &Path) -> Result<Vec<i16>, String> {
    let wav = wav::read(path)?;
    if wav.sample_rate != RATE {
        return Err(format!(
            "{}: частота {}, а стенд работает только на {RATE}",
            path.display(),
            wav.sample_rate
        ));
    }
    Ok(wav.pcm)
}
```

```rust
/// Ошибка по символам.
///
/// Отдельно от WER, потому что отвечает на другой вопрос. Движок,
/// перепутавший окончание, теряет **целое слово** по WER и почти ничего
/// по CER; движок, выдумавший предложение, теряет по обоим. Разница
/// между двумя числами и есть подсказка, какого рода ошибка перед нами.
pub fn cer(reference: &str, hypothesis: &str) -> f32 {
    let reference: Vec<char> = normalize(reference).join(" ").chars().collect();
    let hypothesis: Vec<char> = normalize(hypothesis).join(" ").chars().collect();
    if reference.is_empty() {
        return if hypothesis.is_empty() { 0.0 } else { 1.0 };
    }
    let distance = edit_distance(&reference, &hypothesis);
    distance as f32 / reference.len() as f32
}
```

```rust
mod tests {
    use super::*;
    use domain::TranscriptSegment;

    /// Ожидаемое выводится из входа, а не вписывается числом.
    #[test]
    fn segment_lengths_are_measured_not_guessed() {
        let segments = vec![
            TranscriptSegment::new(0, 1000, "раз"),
            TranscriptSegment::new(2000, 5000, "два"),
            TranscriptSegment::new(6000, 6500, "три"),
        ];
        let stats = segment_stats(&segments, &[], 10_000);
        assert_eq!(stats.count, 3);
        assert_eq!(stats.median_ms, 1000, "медиана из 500, 1000, 3000");
        // Покрытие: 1000 + 3000 + 500 из 10000.
        let expected: f32 = (1000.0 + 3000.0 + 500.0) / 10_000.0;
        assert!((stats.coverage - expected).abs() < 1e-6, "{stats:?}");
    }

    /// Граница считается попавшей в паузу, если речи вокруг неё нет.
    ///
    /// Это и есть мера «режем по речи или по часам»: у нарезки окнами
    /// границы падают куда попало, у нарезки по VAD — в тишину.
    #[test]
    fn a_boundary_inside_speech_does_not_count_as_a_pause() {
        let segments = vec![
            TranscriptSegment::new(0, 3000, "раз"),
            TranscriptSegment::new(3000, 6000, "два"),
        ];
        // Речь идёт сплошняком — граница на 3000 мс попала в середину.
        let speech = [(0u64, 6000u64)];
        let stats = segment_stats(&segments, &speech, 6000);
        assert_eq!(stats.boundaries_in_pause, 0.0);

        // А теперь пауза ровно там же.
        let speech = [(0u64, 2500u64), (3500u64, 6000u64)];
        let stats = segment_stats(&segments, &speech, 6000);
        assert_eq!(stats.boundaries_in_pause, 1.0);
    }

    /// Пустой вход не должен выглядеть как удачный прогон.
    #[test]
    fn no_segments_is_not_full_coverage() {
        let stats = segment_stats(&[], &[], 10_000);
        assert_eq!(stats.count, 0);
        assert_eq!(stats.coverage, 0.0);
    }
}
```

```rust
//! Метрики нарезки: сколько реплик, какой длины, где границы.
//!
//! Отвечают на вопрос, ради которого затевался стенд: режет ли проход по
//! речи или по часам. Нарезка окнами даёт ровные тридцать секунд и
//! границы в случайных местах; нарезка по VAD — разброс длин и границы
//! в паузах.

use domain::TranscriptSegment;

/// Полуокно, в котором ищется тишина вокруг границы, мс.
const PAUSE_WINDOW_MS: u64 = 200;

#[derive(Debug, Clone, PartialEq)]
pub struct SegmentStats {
    pub count: usize,
    pub median_ms: u64,
    pub p10_ms: u64,
    pub p90_ms: u64,
    /// Доля записи, покрытая сегментами.
    pub coverage: f32,
    /// Доля внутренних границ, попавших в паузу. `NaN` не бывает: при
    /// одном сегменте границ нет и доля равна нулю.
    pub boundaries_in_pause: f32,
}

pub fn segment_stats(
    segments: &[TranscriptSegment],
    speech: &[(u64, u64)],
    total_ms: u64,
) -> SegmentStats {
    let mut lengths: Vec<u64> = segments
        .iter()
        .map(|segment| segment.end_ms.saturating_sub(segment.start_ms))
        .collect();
    lengths.sort_unstable();
    let covered: u64 = lengths.iter().sum();

    let mut in_pause = 0usize;
    let mut boundaries = 0usize;
    for pair in segments.windows(2) {
        boundaries += 1;
        let boundary = pair[1].start_ms;
        if !speech_around(speech, boundary) {
            in_pause += 1;
        }
    }

    SegmentStats {
        count: segments.len(),
        median_ms: quantile(&lengths, 0.5),
        p10_ms: quantile(&lengths, 0.1),
        p90_ms: quantile(&lengths, 0.9),
        coverage: if total_ms == 0 {
            0.0
        } else {
            covered as f32 / total_ms as f32
        },
        boundaries_in_pause: if boundaries == 0 {
            0.0
        } else {
            in_pause as f32 / boundaries as f32
        },
    }
}

/// Есть ли речь в окне вокруг метки.
fn speech_around(speech: &[(u64, u64)], at_ms: u64) -> bool {
    let from = at_ms.saturating_sub(PAUSE_WINDOW_MS);
    let to = at_ms + PAUSE_WINDOW_MS;
    speech.iter().any(|(start, end)| *start < to && *end > from)
}

fn quantile(sorted: &[u64], q: f32) -> u64 {
    if sorted.is_empty() {
        return 0;
    }
    let index = ((sorted.len() - 1) as f32 * q).round() as usize;
    sorted[index.min(sorted.len() - 1)]
}
```

```rust
//! cpWER: правильное ли слово попало правильному говорящему.
//!
//! Ни WER, ни DER на этот вопрос не отвечают. WER не знает про людей
//! вовсе; DER считает время, а не слова, и запись, где каждому отдана
//! верная доля секунд с полностью перепутанным текстом, у него отличная.
//!
//! Считается так: текст каждого говорящего склеивается по правде и по
//! гипотезе, метки сопоставляются перебором, берётся сопоставление с
//! наименьшей суммарной ошибкой. Перебор законен, пока людей единицы;
//! на большем числе он отказывает, а не считает наугад.

use crate::wer::wer;

/// Больше этого числа голосов перебор не судит.
const MAX_SPEAKERS: usize = 6;

pub fn cpwer(
    truth: &[(u64, u64, String, String)],
    hypothesis: &[(u64, u64, String, String)],
) -> Result<f32, String> {
    let truth_labels = labels(truth);
    let hypothesis_labels = labels(hypothesis);
    if truth_labels.len() > MAX_SPEAKERS || hypothesis_labels.len() > MAX_SPEAKERS {
        return Err(format!(
            "перебор сопоставлений не судит больше {MAX_SPEAKERS} голосов: \
             в правде {}, в гипотезе {}",
            truth_labels.len(),
            hypothesis_labels.len()
        ));
    }
    // ... перебор перестановок hypothesis_labels, для каждой —
    // сумма расстояний по склеенному тексту, делённая на число слов
    // правды; берётся минимум.
    todo_minimum(&truth_labels, &hypothesis_labels, truth, hypothesis)
}
```

```rust
fn labels(turns: &[(u64, u64, String, String)]) -> Vec<String> {
    let mut out: Vec<String> = turns.iter().map(|turn| turn.3.clone()).collect();
    out.sort();
    out.dedup();
    out
}

/// Склеить текст одного говорящего по времени.
fn joined(turns: &[(u64, u64, String, String)], label: &str) -> String {
    let mut picked: Vec<&(u64, u64, String, String)> =
        turns.iter().filter(|turn| turn.3 == label).collect();
    picked.sort_by_key(|turn| turn.0);
    picked
        .iter()
        .map(|turn| turn.2.as_str())
        .collect::<Vec<_>>()
        .join(" ")
}

fn permutations(items: &[String]) -> Vec<Vec<String>> {
    if items.is_empty() {
        return vec![Vec::new()];
    }
    let mut out = Vec::new();
    for (index, item) in items.iter().enumerate() {
        let mut rest = items.to_vec();
        rest.remove(index);
        for mut tail in permutations(&rest) {
            let mut one = vec![item.clone()];
            one.append(&mut tail);
            out.push(one);
        }
    }
    out
}
```

```rust
//! Выкладка встречи из данных приложения в случай стенда.
//!
//! Гоняется на Маке — там лежат встречи, — а результат переезжает на
//! машину, где идёт разработка. Отдельная подкоманда, а не отдельный
//! прибор: формат случая знает стенд, и вторая его реализация разошлась
//! бы с первой.

use std::path::Path;

use domain::AudioChannel;
use storage::AudioManifestStore;

use crate::wav;

pub fn export(data_root: &Path, meeting_id: &str, out_dir: &Path) -> Result<(), String> {
    std::fs::create_dir_all(out_dir).map_err(|error| format!("{}: {error}", out_dir.display()))?;
    let store = AudioManifestStore::open(data_root).map_err(|error| error.to_string())?;

    let mic = store
        .read_session_pcm(meeting_id, AudioChannel::Mic)
        .map_err(|error| format!("микрофонный канал: {error}"))?;
    if mic.is_empty() {
        // Пустой канал — отказ, а не случай с тишиной: молчаливо
        // выложенная пустая запись даст движку ноль и прочтётся как
        // «движок ничего не услышал».
        return Err(format!("у встречи {meeting_id} пустой микрофонный канал"));
    }
    wav::write(&out_dir.join("mic.wav"), &mic, 16_000)?;

    let system = store
        .read_session_pcm(meeting_id, AudioChannel::System)
        .unwrap_or_default();
    if !system.is_empty() {
        wav::write(&out_dir.join("system.wav"), &system, 16_000)?;
    }

    let unified = store
        .channel_clock_unified(meeting_id)
        .unwrap_or(false);
    std::fs::write(
        out_dir.join("meta.toml"),
        draft_meta(meeting_id, unified, 0),
    )
    .map_err(|error| format!("meta.toml: {error}"))?;
    Ok(())
}

source = "meetingraft:{meeting_id}"
channel_clock_unified = {channel_clock_unified}
reference_kind = "none"
notes = ""
"#
    )
}
```

```rust
//! Отрезки речи от Silero VAD.
//!
//! Отдельно от `SileroGate`, и это не дублирование. Гейт отвечает на
//! вопрос «сейчас речь?» покадрово и **выбрасывает** накопленные
//! сегменты; здесь нужен ровно противоположный режим — собрать границы
//! реплик. Один объект с двумя режимами означал бы, что живой путь и
//! стенд делят состояние детектора, а они гоняются по-разному.

use std::path::Path;

use sherpa_onnx::{SileroVadModelConfig, VadModelConfig, VoiceActivityDetector};

use crate::vad_path::resolve_vad_model;

const WINDOW_SIZE: i32 = 512;
const BUFFER_SECONDS: f32 = 30.0;
const THRESHOLD: f32 = 0.5;
/// Пауза короче этой реплику не разрывает.
const MIN_SILENCE: f32 = 0.35;
/// Речь короче этой отрезком не считается.
const MIN_SPEECH: f32 = 0.2;

/// Границы отрезков речи, мс от начала записи.
pub fn speech_segments(
    data_root: impl AsRef<Path>,
    pcm: &[i16],
    sample_rate: u32,
) -> Result<Vec<(u64, u64)>, String> {
    if pcm.is_empty() {
        return Ok(Vec::new());
    }
    let model = resolve_vad_model(data_root)?;
    let config = VadModelConfig {
        silero_vad: SileroVadModelConfig {
            model: Some(model.to_string_lossy().into_owned()),
            threshold: THRESHOLD,
            min_silence_duration: MIN_SILENCE,
            min_speech_duration: MIN_SPEECH,
            window_size: WINDOW_SIZE,
            max_speech_duration: BUFFER_SECONDS,
        },
        sample_rate: sample_rate as i32,
        num_threads: 1,
        ..VadModelConfig::default()
    };
    let mut detector = VoiceActivityDetector::create(&config, BUFFER_SECONDS)
        .ok_or_else(|| "sherpa-onnx не открыл модель VAD".to_string())?;

    let samples: Vec<f32> = pcm.iter().map(|s| *s as f32 / 32768.0).collect();
    let mut out = Vec::new();
    for chunk in samples.chunks(WINDOW_SIZE as usize) {
        detector.accept_waveform(chunk);
        while !detector.is_empty() {
            let segment = detector.front();
            let start_ms = segment.start() as u64 * 1000 / u64::from(sample_rate);
            let end_ms = start_ms + segment.n() as u64 * 1000 / u64::from(sample_rate);
            out.push((start_ms, end_ms));
            detector.pop();
        }
    }
    detector.flush();
    while !detector.is_empty() {
        let segment = detector.front();
        let start_ms = segment.start() as u64 * 1000 / u64::from(sample_rate);
        let end_ms = start_ms + segment.n() as u64 * 1000 / u64::from(sample_rate);
        out.push((start_ms, end_ms));
        detector.pop();
    }
    Ok(out)
}
```

```rust
//! Три способа разрезать запись на куски перед распознаванием.
//!
//! Смысл оси — в том, что все три дают внешне одинаковое: список кусков
//! с временем. Разница в том, **откуда взялись границы**, и она видна
//! только в метриках: у окон границы стоят по часам, у VAD — в паузах,
//! у диаризации — на смене голоса.

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Strategy {
    /// Как сегодня работает `GigaamBatchTranscriber`: окна по 30 с.
    /// В стенде — база сравнения, а не кандидат.
    Windows30,
    Vad,
    Diarize,
}

/// Кусок записи, который поедет в движок отдельно.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Piece {
    pub start_ms: u64,
    pub end_ms: u64,
    /// Метка голоса, если её дала нарезка. У окон и VAD её нет вовсе, и
    /// `None` здесь честнее нуля: нулевой кластер — это «первый голос»,
    /// а не «голос неизвестен».
    pub speaker: Option<u32>,
}

/// Длиннее этого кусок не отдаётся движку.
///
/// Нужно всем трём способам: без него нарезка по VAD на непрерывной речи
/// выродилась бы в те же тридцать секунд, только без окон.
pub const MAX_PIECE_MS: u64 = 30_000;

pub fn split_windows(pcm: &[i16], sample_rate: u32, window_ms: u64) -> Vec<Piece> {
    if pcm.is_empty() || sample_rate == 0 {
        return Vec::new();
    }
    let total_ms = pcm.len() as u64 * 1000 / u64::from(sample_rate);
    let mut out = Vec::new();
    let mut start = 0;
    while start < total_ms {
        let end = (start + window_ms).min(total_ms);
        out.push(Piece {
            start_ms: start,
            end_ms: end,
            speaker: None,
        });
        start = end;
    }
    out
}

/// Разрезать длинные куски, сохранив порядок и метки.
pub fn cap_length(pieces: Vec<Piece>) -> Vec<Piece> {
    let mut out = Vec::new();
    for piece in pieces {
        let mut start = piece.start_ms;
        while piece.end_ms.saturating_sub(start) > MAX_PIECE_MS {
            out.push(Piece {
                start_ms: start,
                end_ms: start + MAX_PIECE_MS,
                speaker: piece.speaker,
            });
            start += MAX_PIECE_MS;
        }
        if piece.end_ms > start {
            out.push(Piece {
                start_ms: start,
                end_ms: piece.end_ms,
                speaker: piece.speaker,
            });
        }
    }
    out
}
```
