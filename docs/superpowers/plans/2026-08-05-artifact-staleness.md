# План: артефакт, разошедшийся с транскриптом

Спека: `docs/superpowers/specs/2026-08-05-artifact-staleness-design.md`.

## T1 — отпечаток в `domain`

`body_fingerprint(&str) -> String`, FNV-1a 64. Тесты: одинаковый текст —
одинаковый отпечаток; изменение одного символа меняет; значение
зафиксировано константой в тесте, чтобы обновление Rust не переписало
молча то, что уже лежит в базах.

## T2 — миграция и хранение

`source_version INTEGER`, `source_fingerprint TEXT` в `artifacts`, обе
NULL-able, отдельной миграцией через `ALTER TABLE`. `domain::Artifact`
получает `source_version: Option<u32>` и `source_fingerprint:
Option<String>`.

Тест: существующая база без колонок открывается, старый артефакт читается
с `None` в обоих полях.

## T3 — запись при сборке

`store_generated_artifact` получает версию и тело Final, из которого
собирал, и пишет отпечаток. Ветки backend / локальной LLM / встроенных
шаблонов — все три.

Тест: сгенерированный артефакт несёт версию и отпечаток текущего Final.

## T4 — признак отставания на границе

`FfiArtifact` + `is_stale: bool`, `source_version: u32` (0 — неизвестно).
Свободная функция считает признак: нет полей → не отставший; версия не
совпала с последней → отставший; отпечаток не совпал → отставший.

Тесты, каждый должен падать без своей ветки:

- правка сегмента после сборки → `is_stale`;
- **переименование спикера после сборки → `is_stale`** (случай, который
  время последней правки не ловит);
- пересбор в новую версию → `is_stale`;
- ничего не трогали → не `is_stale`;
- артефакт из старой базы (поля NULL) → не `is_stale`.

## T5 — плашка в Artifacts

Вкладка Artifacts: у отставшего артефакта плашка «собран до правок
транскрипта» и кнопка пересборки, зовущая существующий путь генерации с
видом этого артефакта. Проверяется на Маке.
