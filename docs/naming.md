# Naming

## Decision

The product name is **MeetingRaft**, matching the repository name
`meetingraft`. Product name and repository name are intentionally the same
to avoid a split identity between docs, code, and the GitHub URL.

- Display form: `MeetingRaft` (titles, prose, UI).
- Technical form: `meetingraft` (repo, bundle ids, package names).

## History

Earlier working name: **BriefLane** (retired 2026-08-02 in favor of the
repository name).

Alternatives considered at the time:
- EchoBrief
- MeetSlate
- TraceNote
- CallCanvas
- LaneNote
